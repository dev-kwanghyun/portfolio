# 김광현 · Quest Log

픽셀아트 게임 콘셉트의 프론트엔드 개발자 포트폴리오입니다.

캐릭터 선택 → 스킬 장착 → 스테이지(프로젝트) 선택 순서로 진행되며, `#summary`에서 모든 스테이지를 한 번에 볼 수 있습니다.

## 기술

React · TypeScript · Vite · Tailwind CSS · 픽셀 폰트 [Galmuri](https://github.com/quiple/galmuri) (OFL)

## 실행

```sh
npm install
npm run dev     # 개발 서버
npm run build   # dist/ 에 빌드
```

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다.
